# Brief: name brainstorm session

*Self-contained brief for a fresh session. Goal: land the product name (and matching npm package / MCP server name) for the project scoped in [SCOPE.md](SCOPE.md). Read that first — this brief only carries what a naming session needs.*

## What the product is

An MCP server that makes your coding agent your networker. It quietly captures approved snippets of what you're building, and a matching layer (concierge at first) privately compares them across users to output exactly one thing: an introduction to the right person. No feed, no likes, no faces, no performance.

**The one-liner the name has to live next to:**
> "Your agent knows what you're building better than anyone. We make it your networker — a social network with no feed, no faces, and no performance, that only ever outputs one thing: the right person, today."

## Qualities the name should carry

- **Anti-performance / no facade** — the whole positioning is against LinkedIn/X build-in-public cringe. Nothing hype-y, nothing that sounds like a social network.
- **Quiet until it matters** — snippets go into a "black hole"; silence is the resting state; the only output is an intro. Names that evoke privacy, off-the-record, things developing unseen, all fit.
- **The agent as emissary** — your agent pitches your work on your behalf.
- **"The right person"** — warmth of a genuine connection, not networking-as-grind.
- Audience: AI-native builders (first niche: people building MCP servers/agents). Dev-culture resonance is a plus; corporate or dating-app tones are a miss.

## Matthew's naming taste (from his taste profile — calibrate to this)

- Concrete and grounded beats abstract/visionary; he's explicitly repelled by esoteric hype and mission-wash.
- Aesthetics is a named personal value — the name should feel crafted, and it seeds the visual identity.
- Wit lands well (see: "Introvert" surviving to the shortlist).
- His prior project names: Lehren (German, plain, means "to teach"), Viertel (German, "quarter/neighborhood") — he likes short, real words with meaning, including non-English ones.

## Existing candidates (from SCOPE.md — starting point, not a boundary)

- **Backchannel** — front-runner. Private, off-the-record, agents talking behind the scenes.
- **Wavelength** — "someone on your wavelength."
- **Introvert** — cheeky: the network for people who hate networking.
- **Emissary** — your agent pitches for you; slightly formal.
- **Darkroom** — develops quietly in the dark; maybe too moody.
- **Kismet** — the fateful meeting; consumer-warm, less dev.

## Hard constraints / checks (do these for any finalist)

1. **npm package name available** (or a clean scoped variant) — the server ships on npm.
2. **Domain** — something reasonable available (.dev / .so / .app fine; .com not required).
3. **MCP registry / directory collision** — search mcp.so, Smithery, PulseMCP, the official MCP registry, and GitHub for existing MCP servers or dev tools with the name.
4. **Trademark smell-test** — no obvious collision with a funded company in dev tools or social. (Note: Backchannel has prior art risk — a known VC fund "Backchannel" and past products; check properly.)
5. **The tool names matter as much as the brand for agent discovery** — the primary MCP tool is `find_collaborator(need)` regardless of brand; the *server* name + description are what agents semantic-search. The brand can be evocative because the tool interface does the literal-match work.

## How to run the session (Matthew's stated working preference)

Creative steps are **interactive, one option at a time, with reasoning shown** — not a dump of 30 names. Propose one name (or a tight themed cluster), say *why it fits the qualities above*, get his reaction, learn from it, iterate. His corrections are the product — they sharpen what the name needs to be. Run collision checks (npm/domain/registry) before pitching a name as a serious finalist, so no favorite dies after he's attached.

## Deliverable

One chosen name + verified npm package name + domain to register + a one-line rationale, appended to SCOPE.md (replace the "Name candidates" section with the decision and move the also-rans to a footnote). GitHub repo goes on his personal account (matthewwilliams949-ops).
